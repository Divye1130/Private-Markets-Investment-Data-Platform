# Target-role alignment

This project was designed to demonstrate the cluster of skills expected in modern financial-services data engineering:

- Python and SQL data pipelines;
- lakehouse-style Bronze/Silver/Gold processing;
- PySpark/Delta deployment assets for Databricks;
- formal Data Vault 2.0 and Kimball modelling;
- data quality, quarantine, correction history and reconciliation;
- investment-management entities and private-markets performance measures;
- document extraction with deterministic controls and an optional model-serving seam;
- automated testing, CI and a self-service dashboard.

It is deliberately not a generic ML project. The emphasis is trusted financial data products, auditability and business-facing outputs.
